# AutoLoc

Multi-agency vehicle rental management platform (UP ASI, ESPRIT).

## Objectives
- Manage vehicles, agencies, customers and rental contracts
- Build a Java / Spring Boot REST application backed by MySQL

## Actors
- **Client**: searches and books vehicles
- **Agent d'agence**: handles rentals, returns and vehicle availability
- **Responsable d'agence**: manages the agency's agents, fleet and reports
- **Administrateur**: manages agencies, users and global settings

## Stack
Java 17+, Spring Boot, Spring Data JPA, MySQL, Maven, Postman, IntelliJ IDEA
